## Build notes

T01 is built. The shared rule data sits at `lib/Settings/dutch-formats.json` rather than `src/data/dutch-formats/`, because the PHP check reads it at runtime and `lib/` ships with the app. `src/services/dutchFormats.js` imports the same file. T04 is half done: `lib/Service/DutchFormatValidator.php` reads that data and passes the same samples, but it is not yet called on save. The form save listener (`FormLiveValuesListener`) only sees forms in the live-value index, so it needs that index to learn about fields with a Dutch `format` first; T04 stays open for that. T02, T03 and T06 are built since. T04 is complete: the live form index now records each form field's `format`, so a form whose only server-side rule is a Dutch format is indexed too, and `FormLiveValuesListener` checks and normalises those fields before any calculation, refusing a bad value with 422 and the format's message. T05 (Playwright) and T07 (`openspec validate`) are left for a run with a browser and the openspec CLI.
